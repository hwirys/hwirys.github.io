# 추격자 페인팅 v1

사용자의 2026-10-25 요청에 따라 회수반·봉쇄반·보호자에 한정해 imagegen built-in으로 제작한 AI 원화입니다. 스타일 참조는 기존 주인공 `assets/explorer-walk-v2.png`이며 주인공·지도 원본은 변경하지 않았습니다.

- 회수반: 천 머리싸개, 도자기 가면, 낡은 작업 앞치마.
- 봉쇄반: 어두운 작업 외투, 두건과 차광면.
- 보호자: 창백한 얼굴, 낡은 외투와 붉은 목도리.

각 캐릭터는 상하좌우·대각선 8방향과 정지 상태를 지원합니다. 방향마다 정지 1장과 보행 4장을 사용해 총 120프레임을 제공합니다. 회수반의 빠진 뒤쪽 왼쪽 방향은 별도의 AI 생성 원화로 보완했습니다. 원화의 실제 방향을 확인해 배열하며, 이미지 자체를 회전시켜 방향을 대체하지 않습니다.

투명 PNG 원본을 보존하고 게임에서 프레임 선택·등비 크기 정렬·몸통 중심 정렬을 합니다. 각 방향의 정지 키를 주인공의 실제 보이는 키에 맞추고 모든 보행 자세를 같은 비율로 유지합니다. 표시 크기는 주인공과 같은 32×48, 발 기준선은 같은 142/144입니다.
