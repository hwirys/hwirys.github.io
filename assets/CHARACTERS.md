# 캐릭터 아트와 외부 스프라이트 교체

2026-10-22 사용자 요청으로 플레이어와 동행 손님을 LPC 교체 이전 모습으로 복원했다.

현재 플레이어는 `explorer-walk-v2.png`의 익명 성인 초대 손님이다. 같은 코트·목도리·가방을 유지하고 교대 보행과 통과 자세를 보완했다. imagegen 내장 편집 도구로 만든 투명 PNG이며, 16개 프레임의 알파 462,803픽셀과 머리·발 경계를 검사했다. 최종 프롬프트는 소스 저장소의 `docs/PLAYER-WALK-V2.md`에 있다. 기존 `explorer-atlas.png`는 보존하지만 부팅 시 요청하지 않는다.

2026-10-25: 추격자는 살아 있는 회수반·봉쇄반 작업원과 낡은 리본의 보호자 반죽이로 변경했다. `authored/characters/`에 포함된 LPC Revised의 몸·머리·셔츠·바지·신발·가디건·머리카락 원본을 겹쳐 쓰며, 가디건과 머리카락의 조합으로 세 역할을 구분한다. 각 방향의 걷기 8프레임·대기 자세와 원본 픽셀을 그대로 사용한다. 출처·제작자·원본 경로·해시는 `authored/characters/sources.json`, 라이선스는 같은 폴더의 OGA-BY-3.0 문서에 있다. 이전 좀비 원본은 보존하지만 현재 게임에서는 요청하거나 사용하지 않는다.

기존 `party-guest-v1.png`는 보존하지만 본편의 도움 NPC는 회수 대장으로 바뀌었다. 초반 보호자는 작업반과 같은 LPC 원본을 다른 조합으로 사용한다. 하역장에는 추가 인물이 등장하지 않는다. 이 파일과 플레이어는 기존 생성 이미지이므로 게임 전체가 외부 작가의 어셋으로 교체되었다는 뜻은 아니다. 모든 인물은 창작 캐릭터이며 실제 인물의 외모를 참조하지 않았다.

`presence-atlas.png`와 `unattended-operator-v1.png`는 이전 원본으로 보존하지만 현재 부팅 시 요청하지 않는다. 이전 방송실 제목 이미지도 부팅 시 내려받지 않고, 배식대·접시·열쇠·축배를 사용하는 코드 기반 정적 제목 그림으로 대체했다.

`authored/characters/`의 LPC 원본과 출처는 이전 적용 기록으로 보존하지만 현재 회수반·봉쇄반·보호자에 사용한다. 플레이어 원본은 유지한다.

사용자 소유 에셋으로 바꾸려면 아래 파일을 넣고 명시적으로 옵션을 켠다.
외부 파일이 없으면 기본 아틀라스, 기본 아틀라스도 읽을 수 없을 때만 절차 생성 폴백을 사용한다.

## 떨어뜨릴 파일

| 파일 | 용도 |
|------|------|
| `public/assets/char_player.png` | 익명 플레이어의 선택 교체 파일 |
| `public/assets/authored/pursuer/clint-zombie.png` | 추적자 원본(8방향 × 36프레임) |

그리고 `src/config/constants.ts`에서 `USE_EXTERNAL_CHARACTER_SHEETS = true`로 바꾼 뒤
`npm run dev` (또는 `build:web`)를 다시 실행하면 적용됩니다.
(이 플래그가 false인 기본 상태에서는 사용자 외부 파일을 요청하지 않습니다.)

## 필수 레이아웃

- **4열 × 4행** 균일 프레임 그리드 한 장.
- 행 순서(위→아래): **아래 / 왼쪽 / 오른쪽 / 위** (DOWN, LEFT, RIGHT, UP).
- 각 행은 **걷기 4프레임**.
- 투명 배경의 프레임 크기는 자유다. 알파 경계를 확인하여 동일 축척으로
  96×144 렌더링 셀에 정렬하고, 게임에서는 기존 **32×48** 크기로 표시한다.
  높은 해상도의 시트를 넣어도 충돌·타일·발끝 위치는 바뀌지 않는다.

```
[D0][D1][D2][D3]   ← 아래 보기 걷기 4프레임
[L0][L1][L2][L3]   ← 왼쪽
[R0][R1][R2][R3]   ← 오른쪽
[U0][U1][U2][U3]   ← 위
```

> 받은 팩의 레이아웃이 다르면(LPC식 9프레임, 행 순서 다름, 오른쪽=왼쪽 반전 등)
> 그대로 떨어뜨리지 말고 알려주세요 — 해당 포맷용 변환을 코드에 추가하겠습니다.
